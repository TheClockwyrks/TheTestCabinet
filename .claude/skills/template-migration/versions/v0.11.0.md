# v0.11.0

## What the update brings

The devcontainer's compose file states `x-podman.in_pod: false`, so
podman-compose creates no pod beside a rootless Podman host's `keep-id` user
namespace, and the container starts from an editor's Reopen in Container as it
does from a scripted bring-up.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Recreate the devcontainer on every machine the workspace is worked on, so the
  container is started with what this version declares (an editor's Rebuild
  Container, or `devcontainer up --remove-existing-container`).
