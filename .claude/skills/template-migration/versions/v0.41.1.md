## What the update brings

Every `FROM` of `.devcontainer/ubuntu.dockerfile` that names a published image
names the platform too, `--platform=$TARGETPLATFORM`, which the builder
supplies.

- A `FROM` without it builds from whatever the machine's image store holds
  under the tag. One `podman pull --platform` of the other architecture, by
  any workspace on the machine, pointed the shared tag at that image, and every
  devcontainer build on the machine then failed at its first `RUN` with
  `exec format error`. With the platform named, Podman compares the stored
  image with it and pulls the one built for the machine in its place.
- `.devcontainer/README.md` states this under "The published images", and
  `.cspell/project-words.txt` knows `TARGETPLATFORM`.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Where the project edited a `FROM` line or the `ARG TARGETARCH` comment above
  the Android stage, the merge leaves both versions between conflict markers:
  keep the project's line with `--platform=$TARGETPLATFORM` added after `FROM`.
- A machine whose store already holds a tag of the wrong platform needs no
  step: the first build after the update pulls the right image over it.
