## What the update brings

The template stops rendering the `clean` declaration, which Nyxsis no longer
reads now that it reclaims no workspace's build output.

- `.nyxsis/project.toml` declares no `clean = ["make", "clean"]`. The file
  holds the `[cloud]` table alone, as the project left it.
- The `nyxsis` skill states no `clean` key, and no longer names a `make`
  target the clean command runs.
- The `Makefile`'s `clean` target stays, as the developer command `README.md`
  names.

## Questions

is.

## Steps by hand

- Where the project changed the `clean` line, the merge leaves it between
  conflict markers: delete it, since Nyxsis ignores the key. Anything the
  project's own declared command removed belongs in the `Makefile`'s `clean`
  target.
