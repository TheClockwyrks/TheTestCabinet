# v0.20.3

## What the update brings

A fix for the devcontainer image. Claude Code grants a default of bypass
permissions mode only from its managed settings, a user's settings or a
`--settings` file, and ignores the mode in a checkout's `.claude/settings.json`,
so the image now carries the mode in `/etc/claude-code/managed-settings.json`.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Rebuild the devcontainer on every machine the workspace is worked on, so the
  container runs the image this version installs (an editor's Rebuild Container,
  or `devcontainer up --remove-existing-container`).
