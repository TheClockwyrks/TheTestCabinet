# v0.5.0

## What the update brings

The devcontainer installs three browser engines and their system libraries, and
the web app gains a second vitest project that runs its `*.browser.test.tsx`
files in those engines, with a `web-browser-test` commit hook running it. An
update brings both beside what the workspace holds.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Rebuild the devcontainer on every machine the workspace is worked on, so the
  container runs the image this version installs (an editor's Rebuild Container,
  or `devcontainer up --remove-existing-container`).
- Run `npm ci` once the merge lands, so `node_modules` holds the tree the merged
  `package-lock.json` records.
