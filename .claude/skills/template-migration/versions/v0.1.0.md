# v0.1.0

## What the update brings

The first version. A workspace is copied at it rather than updated to it, so no
update brings it: a workspace recording `_commit: v0.1.0` was rendered from it.

It renders a Cargo workspace holding a standard-library HTTP server, the
documentation site, the devcontainer with the Rust and Node toolchains, the
Claude Code and Codex CLIs, the harness's settings, gate hooks and skills, the
issues board under `tasks/`, and the Kubernetes manifests with a local k3d
cluster.

## Questions

It asks `project_name`, `project_description`, `memory_max_gib`, `cpu_shares`,
`clean_command` and `image_registry`, and derives `project_slug` from the name.

## Steps by hand

There is no step to take by hand.
