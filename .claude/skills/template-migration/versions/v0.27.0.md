## What the update brings

Where `tauri_desktop` is answered, `scripts/desktop-build.sh` and its table test
are rendered and `make desktop` runs the script, which builds the one package
the machine's platform installs, an AppImage on Linux and a disk image on macOS,
and copies it, given `<PROJECT>_ARTIFACT_DIR`, into that directory. The Android
CI image installs `file` and `patchelf`, which the AppImage bundler shells out
to.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Where the workspace builds the Android application, the Android CI image
  changes. Where the merge changed a file the image pipeline triggers on (its
  path filter in `azure-pipelines-ci-images.yml` is the one list of them), push
  the merge, let the image pipeline's run on it push every image, then write
  that commit into `ciImageTag` in `ci/images/tags.yml` and commit it. The gates
  run in the images the old pin names until that second commit lands.
