## What the update brings

Where the project keeps issues in files, `.nyxsis/project.toml` declares an
`[issues]` table naming `format = "files"` and `root = "tasks"` beside the clean
command. The render check holds the table to the answer.

## Questions

It asks `issues_format` in the Project stage, after `project_description`:
`files`, the default, or `none`. A workspace that predates it records no answer;
an update run with `--defaults` takes `files` and records it, and a tool
applying the update asks it.

## Steps by hand

- Where the workspace keeps no issues on a board, answer `none`, or delete the
  `[issues]` table from `.nyxsis/project.toml` and record `issues_format: none`
  in `.copier-answers.yml`.
