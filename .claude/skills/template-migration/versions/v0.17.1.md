# v0.17.1

## What the update brings

A fix for the Android toolchain. Its install opens what the SDK manager unpacked
under `ANDROID_HOME` to every user, and the Android CI image opens it to write
as well and runs `java`, `adb` and the NDK's `clang` as uid 1001 before its
build finishes, so the steps Azure runs as that uid find the SDK usable. It
changes a workspace that builds the Android application alone.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Where the workspace builds the Android application: rebuild the devcontainer
  on every machine the workspace is worked on, and pin the Android CI image
  again. Where the update changed a file a CI image is built from, the
  `ci-tests` gate fails naming the tag the image's inputs now hash to. Follow
  `ci/images/README.md`: write the tag it names, push, let the image pipeline's
  run push the image, and queue the gates again.
