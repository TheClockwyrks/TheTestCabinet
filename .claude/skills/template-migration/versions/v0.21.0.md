## What the update brings

The Tauri pins move to 2.12.0: `TAURI_CLI_VERSION` in the compose file and
`@tauri-apps/cli` in `package.json` name 2.12.0, `Cargo.toml` pins `tauri`
2.12.0 and `tauri-build` 2.7.0, and both lockfiles carry the resolution. The
placeholder icons are drawn again by the 2.12.0 `tauri icon`, whose output
differs, so the `app-icons` gate holds them to what the moved CLI draws. The
Android manifest asks `android.permission.POST_NOTIFICATIONS` beside `INTERNET`.

## Steps by hand

- Rebuild the devcontainer on every machine the workspace is worked on, so the
  container runs the image this version installs (an editor's Rebuild Container,
  or `devcontainer up --remove-existing-container`).
- Run `npm ci` once the merge lands, so `node_modules` holds the tree the merged
  `package-lock.json` records.
- Where the project owns its seeds, run `make icons` once and commit what it
  draws.
