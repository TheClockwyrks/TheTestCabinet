# v0.26.0

## What the update brings

Every test gate's JUnit report is published as the run's test results. The
`web-test` and `ci-tests` steps of `azure-pipelines.yml` name
`CI_GATE_ARTIFACTS: target/gate-artifacts/<id>` as the `rust-test` and
`web-browser-test` steps do, each gains a `PublishTestResults@2` step, and the
`rust` and `web` jobs end with `scripts/ci/collect-test-results.sh` and the
publish of its directory as the pipeline artifact
`test-results-<job>-$(System.JobAttempt)`, whether the tests passed or failed.
