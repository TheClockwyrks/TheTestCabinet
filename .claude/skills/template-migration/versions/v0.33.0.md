# v0.33.0

## What the update brings

The render carries the `template-migration` skill,
`.claude/skills/template-migration/SKILL.md`, with one guide per template
version under `versions/`, named by its tag, each stating what that version
brings, the questions it adds or stops asking, and the steps a workspace takes
by hand once the merge lands. `CLAUDE.md` and `.claude/README.md` name it and
say when to read it, every later version adds its own guide, and `copier update`
ends by pointing at the skill.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

There is no step to take by hand.
