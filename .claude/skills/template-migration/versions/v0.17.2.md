# v0.17.2

## What the update brings

A fix to `v0.17.1`. `adb` aborts where it cannot create `~/.android`, and `HOME`
is widened only by the image's last layer, so the three programs run as uid 1001
with a scratch `HOME` that uid can write, and `v0.17.1`'s Android CI image,
which failed to build, builds. It changes a workspace that builds the Android
application alone.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Where the workspace builds the Android application, pin the Android CI image
  again. Where the update changed a file a CI image is built from, the
  `ci-tests` gate fails naming the tag the image's inputs now hash to. Follow
  `ci/images/README.md`: write the tag it names, push, let the image pipeline's
  run push the image, and queue the gates again.
