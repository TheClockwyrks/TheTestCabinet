# v0.12.0

## What the update brings

The image drops the `DOCKER_GID` build argument and joins the container user to
the runtime socket's group at every start instead, so every path that starts the
container builds the same image. The CI image scripts drop the argument too.

## Questions

It adds no question and stops asking none, so every recorded answer stays as it
is.

## Steps by hand

- Rebuild the devcontainer on every machine the workspace is worked on, so the
  container runs the image this version installs (an editor's Rebuild Container,
  or `devcontainer up --remove-existing-container`).
- Where the update changed a file a CI image is built from, the `ci-tests` gate
  fails naming the tag the image's inputs now hash to. Follow
  `ci/images/README.md`: write the tag it names, push, let the image pipeline's
  run push the image, and queue the gates again.
