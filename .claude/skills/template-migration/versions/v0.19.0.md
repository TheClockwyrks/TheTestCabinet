## What the update brings

The desktop crate's icons are drawn from a source the project owns: `app-icon/`
holds the icon's image, the adaptive launcher icon's foreground where the
project builds the Android application, and `icon.json` naming them and their
ground color, seeded with the template's placeholder mark. Every size under
`icons/` and every Android launcher icon is drawn from it by the pinned `tauri
icon` through `make icons`, and a new `app-icons` gate fails on a committed icon
that is not what the source draws.

An update brings the source, the script and the gate into every workspace that
builds the desktop application, and replaces `icons/source.svg` with
`app-icon/icon.svg` where the template owns the seeds.

## Steps by hand

- Where the project owns its seeds (`seed_files` answered `project`): put the
  project's own mark into `app-icon/`, run `make icons` and commit what it
  draws, so the `app-icons` gate passes.
