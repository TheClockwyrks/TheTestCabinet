## What the update brings

The desktop crate's `tauri.conf.json`, `capabilities/` and `tests/` are seeds,
so a project that owns its seeds states the policy and permissions its
application runs with and no update renders over them. The policy the template
seeds declares `connect-src 'self'` in place of any `https:` origin, and a build
given the backend's address states `connect-src` as that address's origin over
HTTP and WebSocket before it serves the first page.

An update brings the narrow policy into a workspace whose seeds the template
owns, and leaves a workspace that owns them as it is.
