# v0.17.0

## What the update brings

The Rust CI image installs the apt packages a project names for its own tests
beside the toolchain's.

## Questions

It asks `rust_ci_packages`, whose default, none, renders the image as `v0.16.0`
does, so an update changes nothing in a workspace that keeps it.

## Steps by hand

- Where the workspace answers `rust_ci_packages` with packages, the Rust image's
  inputs change: where the update changed a file a CI image is built from, the
  `ci-tests` gate fails naming the tag the image's inputs now hash to. Follow
  `ci/images/README.md`: write the tag it names, push, let the image pipeline's
  run push the image, and queue the gates again.
