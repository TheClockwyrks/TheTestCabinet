# The libraries a Java program may reach, and the whole of what the model is told it has.
#
# WHAT DECIDES THE SET. TeaVM's classlib — a large subset of `java.base`, not the whole of it —
# plus the ThreeTen backport it bundles for `java.time`. There is nothing to install and nothing
# to bake: what a program can reach is what TeaVM can translate, and what it cannot is a LOCATED
# COMPILE ERROR on the turn that wrote it (`program.java:1: Class java.security.MessageDigest was
# not found`) rather than a run-time surprise. That is this arm's most valuable property.
#
# So this file is a claim about the artifact, and it is held to it: `java_reaches_every_library`
# in `crates/gg/src/sandbox/language/java.substrate.test.rs` drives every package below through
# the real javac and the real TeaVM and requires a real class in each to compile AND run. A
# package listed here that the classlib does not carry fails that test rather than reaching a
# model, and the two absences worth knowing about are recorded there as absences.
#
# The `# --- heading ---` lines are the groups the catalogue's `libraries` section renders, and
# that section is what gg quotes back to a model on a COMPILE FAILURE. No system prompt carries a
# package inventory any more: the one mistake this set prevents — a program written against a
# package this arm does not carry — is a mistake the compiler DETECTS, so the set is delivered on
# the turn that made it rather than read on every turn by a model that never writes an import.
# `packages/gg-sandbox-java/tools/GgSignatures.java` reads this file and refuses a package under no
# heading.
#
# gg's own wrapper already imports `gg.*`, `java.util.*`, `java.util.function.*`,
# `java.util.stream.*`, `java.math.*`, `java.time.*`, `java.time.format.*`, `java.text.*` and
# `java.util.regex.*` into every program, so those need no import line; the rest do, and a model's
# own `import` is hoisted into the header for it.
