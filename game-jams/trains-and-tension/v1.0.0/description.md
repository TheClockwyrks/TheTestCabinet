**Trains & Tension** is a game jam — a test case with no specification. Instead of
handing the model a game to build to a bar, it hands over a single **theme** and
asks for a complete, playable, enjoyable game of _any genre_ built around it, with
the model producing all of the game's own art, effects, and sound during the run.

The theme is deliberately open. "Trains" and "tension" can be read a dozen ways — a
signal-box juggling converging services, a heist aboard a moving express, a
runaway locomotive you have to slow, a supply line that must not break, a tug-of-war
on a taut cable — and the jam rewards a reading that genuinely shapes the design.

Runs are judged the way a game jam is judged: a person plays the entry and grades it
on general categories — **Playability**, **Fun**, **Theme**, **Presentation**,
**Audio**, **Polish**, and **Creativity** — on a five-level scale (💩 → 💎), and
gives the game one overall grade. There is no pass/fail checklist and no reference
build to match; the only brief is _make something playable and enjoyable_.
