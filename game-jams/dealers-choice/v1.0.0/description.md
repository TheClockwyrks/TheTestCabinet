**Dealer's Choice** is a game jam — a test case with no specification. Instead of
handing the model a game to build to a bar, it hands over a single **theme** and
asks for a complete, playable, enjoyable game built around it, with the model
producing all of the game's own art, effects, and sound during the run.

The name says it: _dealer's choice_ means the one dealing picks the game — and here
that dealer is the model, which invents the whole card game from scratch. Two things
are fixed. It is a **card game** built on its own designed cards — not the standard
52-card deck, so no poker, solitaire, or rummy family. And, the main requirement, it
must be **original**: a negative constraint that the game may not be a reskin of, or
play out like, a well-known card game. Magic: The Gathering, Hearthstone, Slay the
Spire, Balatro, and their imitators are off the table, and so is any game that merely
re-dresses one of them; the originality has to be _mechanical_. What kind of card game
it is — a deckbuilder, a drafter, a trick-taker, a combo engine, or something with no
name yet — and everything around it is the model's to invent.

The interesting difficulty is making a fresh set of cards whose interactions actually
work and hold together into a game worth playing.

Runs are judged the way a game jam is judged: a person plays the entry and grades it
on general categories — **Playability**, **Fun**, **Theme**, **Presentation**,
**Audio**, **Polish**, and **Creativity** — on a five-level scale (💩 → 💎), and
gives the game one overall grade. There is no pass/fail checklist and no reference
build to match; the only brief is _make something playable and enjoyable_.
