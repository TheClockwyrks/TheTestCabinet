# Inventory brief

Write `notes/inventory.md` describing the workspace root.

## Required content

1. A top-level heading reading `# Workspace inventory`.
2. One Markdown list entry per entry of the workspace's top-level
   directory, in the order the listing returns them.
3. Each entry formatted as `- `, the entry's name, then ` (dir)` for a
   directory or ` (file)` for a file.

## Rules

- List the top-level directory only; do not recurse.
- Create the `notes/` directory as part of the write if it does not exist.
- Change nothing else in the workspace.
