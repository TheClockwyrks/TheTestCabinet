**Lanternjaw** is an anglerfish-style deep-sea pursuer that lures the player with
the glowing light on its head — one of the chasers in a lightless maze-chase
game. This asset-generation case asks a model to draw it as a 64×64 enemy sprite
using only the drawing tool, one operation at a time. The recorded operations are
regenerated into the scored image and compared against the target; the glowing
lure, the toothed maw, and its read as a lurking predator are what a reviewer
weighs.
