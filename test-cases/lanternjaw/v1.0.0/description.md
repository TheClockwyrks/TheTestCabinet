**Lanternjaw** is the Lure — an anglerfish-style deep-sea predator that hunts by
light with a dangling lure-light, one of the chasers in a lightless maze-chase
game. This asset-generation case asks a model to draw it as a **sprite sheet**
using only the drawing tool, one operation at a time: 16 separate 32×32 frames
holding four-direction swim cycles and a lure-bob animation.

The recorded operations are regenerated into each frame, which a reviewer judges
against the brief: the glowing lure, the four readable directions, and the
lure-bob tell are what they weigh, and the named sequences play back as live
animations in the review UI.
