Refract is a puzzle game of light on a dark optical bench: each board is a grid
of emitters, lenses, and charge-carrying crystals, and the player solves it by
drawing one beam per channel with the pointer — the rules run on every move and
silently refuse anything illegal. Everything here was captured from the case's
reference implementation: the title screen, then a three-channel board with a
two-charge crystal, drawn from empty to solved through the game's own pointer
path.
