# Spectra — Sortie

**SCAFFOLD PLACEHOLDER — this is not the showcase.** It exists so
`variants/base.toml`'s `showcase` key resolves while Spectra v2.0.0 is being
built out; the showcase stage replaces this file, `showcase.toml` and the media
beside them.

What lands here is the player-facing presentation of the straight sortie — match the band or waste the shot, captured from
`references/simple-2d/base` through this case's own validator harness with the
engine's recorder: a leading `.json.gz` replay of twenty to forty seconds of
sustained real play, then two stills from the same take. Every outcome on screen
arises from the game's own rules under scripted key input.
