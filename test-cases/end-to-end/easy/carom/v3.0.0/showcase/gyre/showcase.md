Gyre plays Carom's paddle duel with the mid-court obstacles in motion: they
sway vertically and rotate in place, so the ball comes off tilted, oriented
faces instead of upright ones. Everything else — the serve, spin, scoring,
and the AI opponent — is the base game. The replay is a stretch of a real
Solo match against the reference implementation's AI, the rally deflecting
off the turning obstacles until a point lands — captured from the reference
implementation in live play.
