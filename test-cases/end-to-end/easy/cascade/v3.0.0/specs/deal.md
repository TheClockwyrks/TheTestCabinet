# The deck and the deal

This specification file has not been written yet.

**Scope.** The 52-card deck, its four suits, its thirteen ranks with Ace low
and King high, and the two colours; the uniform shuffle at every new game;
seven columns of 1..7, the lowest card of each face-up and the rest face-down;
twenty-four cards to the stock, face-down, in dealing order; the waste and the
four foundations starting empty; and that a new deal clears the painted table,
so a deal following a cascade leaves clean felt.
