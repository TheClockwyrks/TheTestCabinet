# The seven columns and what they accept

This specification file has not been written yet.

**Scope.** Building down in rank and alternating in colour; only a King, or a run headed by a King, onto an empty column; a column whose lowest card is face-down accepts nothing; a contiguous face-up run in descending-alternating order moves as a unit; a grab takes the pressed face-up card and every face-up card below it; a move whose source card is face-down is refused; a column's newly exposed lowest card turns face-up; a refused move returns the cards to where they were picked up.
