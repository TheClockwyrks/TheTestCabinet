# Floe v3.0.0 — the `base` showcase

**PLACEHOLDER — this showcase has not been captured yet.**

The Scaffold stage created this directory because `variants/base.toml` names it
as `showcase = "showcase/base"` and manifest resolution requires it to exist. The
Showcase stage of the Floe v3.0.0 rework replaces it with `showcase.md`,
`showcase.toml`, and the three media files the design plan fixes, captured from
`references/none` driven in Chromium with Playwright:

1. `crossing.webm` — twenty to forty seconds of sustained real play, the leading
   entry.
2. `mid-crossing.png` — a still from the same take, the critter mid-water with a
   submerged bear behind it.
3. `title.png` — the title screen.

Every outcome on screen arises from the game's own rules under scripted input.
Posing an outcome through the debug surface is fabrication and is not used.
