**Gloamfin** is an eyeless deep-sea pursuer that hunts by echolocation — one of
the chasers in a lightless maze-chase game. This asset-generation case asks a
model to draw it as a 64×64 enemy sprite using only the drawing tool, one
operation at a time. The recorded operations are regenerated into the scored
image and compared against the target; the sprite's eyeless silhouette and its
read as a forward-facing predator are what a reviewer weighs.
