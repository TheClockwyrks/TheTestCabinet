**Spectra Prism** is the two-band boss drone from *Spectra*, a two-band
formation shooter — the large anchor of a wave, an outer shell of one band
around an inner core of the opposite band. This asset-generation case asks a
model to draw it as a 64×64 sprite using only the drawing tool, one operation
at a time: a thick cyan shell ring around a magenta core, carrying both band
glyphs at boss scale. The recorded operations are regenerated into the image,
which a reviewer judges against the brief: the two-layer construction and the
band-by-shape read are what they weigh.
