**Foray Soldier** is the defender caste of *Foray*, a top-down ant-colony
raiding game — the heavy, mandibled ant that guards its colony's nest. This
asset-generation case asks a model to draw it as a **sprite sheet** using only
the drawing tool, one operation at a time: four 16×16 facing frames (down, up,
left, right) drawn in a neutral grey ramp so the renderer can recolor it red or
blue per colony by palette swap. The recorded operations are regenerated into
each frame, which a reviewer judges against the brief: the forward mandibles
that mark the fighting caste, the four readable facings, and the neutral
recolorable palette are what they weigh.
