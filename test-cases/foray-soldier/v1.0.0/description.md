**Foray Soldier** is the defender caste of *Foray*, a top-down ant-colony
raiding game — the heavy, mandibled ant that guards its colony's nest. This
asset-generation case asks a model to draw it as an animated **sprite sheet**
using only the drawing tool, one operation at a time: a four-step walk cycle in
each of four facings (down, up, left, right) across sixteen 16×16 frames, drawn
in a neutral grey ramp so the renderer can recolor it red or blue per colony by
palette swap. The recorded operations are regenerated into each frame, and a
reviewer judges them against the brief: the forward mandibles that mark the
fighting caste, a believable scuttling walk cycle in each facing, the four
readable facings, and the neutral recolorable palette are what they weigh.
