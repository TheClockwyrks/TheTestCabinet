**RPG Item Icon Set** is a generic, reusable pack of nine fantasy inventory
icons — a red health potion, a blue mana potion, a steel sword, a round wooden
shield, a gold coin, a treasure chest, a brass key, a gemmed ring, and a rolled
scroll. Because a good icon set has to read instantly at small size *and* hang
together as one cohesive family, it is its own asset-generation case: a model draws
all nine as a **single 96×96 sprite** — a 3×3 grid of 32×32 cells, one icon per
cell — one operation at a time, each icon chunky and boldly outlined with flat
two-tone shading and a shared top-left light, on full transparency. The recorded
operations are regenerated into the sprite, which a reviewer judges against the
brief: whether all nine items read at a glance, whether the outline, shading, and
lighting are consistent across the set, the clean grid layout, and the stated
palette are what they weigh.
