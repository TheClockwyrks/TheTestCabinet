**RPG Item Icon Set** is a generic, reusable pack of nine fantasy inventory
icons: a red health potion, a blue mana potion, a steel sword, a round wooden
shield, a gold coin, a treasure chest, a brass key, a gemmed ring, and a rolled
scroll.

This asset-generation case asks a model to draw all nine as a single 96×96
sprite, a 3×3 grid of 32×32 cells with one icon per cell, one operation at a
time. Each icon is chunky and boldly outlined with flat two-tone shading and a
shared top-left light, on full transparency.

The recorded operations are regenerated into the sprite, which a reviewer judges
against the brief: whether all nine items read at a glance, whether the outline,
shading, and lighting are consistent across the set, whether the grid layout is
clean, and whether it holds to the stated palette.
