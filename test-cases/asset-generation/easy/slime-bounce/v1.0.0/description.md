**Slime Enemy Bounce** is a cute green slime — a soft, jelly-like blob with two
simple eyes, the kind of harmless little enemy that bounces along the ground. This
asset-generation case asks a model to draw it as a **sprite sheet** using only the
drawing tool, one operation at a time: six 32×32 frames of a single squash-and-
stretch hop loop — squashed wide on the ground, stretched tall as it launches,
rounded at the apex, stretched as it drops, and squashed on landing. The recorded
operations are regenerated into each frame, which a reviewer judges against the
brief: whether it reads as a cute green slime, whether the squash-and-stretch reads
as a convincing springy bounce, and whether the loop is clean — played back as a
live animation in the review UI.
