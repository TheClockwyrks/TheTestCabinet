**Foray Large Seed** is the moving prize of *Foray*, a top-down ant-colony
raiding game — a single big golden seed worth (and weighing) three ordinary
caches, and the one fixture on the board that drifts a tile at a time toward the
border. Like an ordinary cache it belongs to neither colony, so the sprite uses
the fixed shared gold palette and is never recolored.

This asset-generation case asks a model to draw it as a 16×16 sprite using only
the drawing tool, one operation at a time: a single large rounded golden kernel
filling most of the tile, outlined so it stays legible on the board, with a
bright glint on top. The recorded operations are regenerated into the image,
which a reviewer judges against the brief: one big seed that reads as the
valuable moving prize — the big sibling of an ordinary cache, not a pile of small
seeds and not a tiny dot.
