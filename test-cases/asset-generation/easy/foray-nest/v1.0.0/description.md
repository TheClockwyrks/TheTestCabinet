**Foray Nest** is a colony's home tile in *Foray*, a top-down ant-colony raiding
game — the spawn mound a raider must reach to bank a carried seed, and the heart
a soldier defends.

This asset-generation case asks a model to draw it as a 16×16 sprite using only
the drawing tool, one operation at a time: a centered, roughly symmetric domed
earth-mound, built up in concentric rings with a clear dark entrance hole at its
center, drawn in a neutral grey ramp so the renderer can recolor it red or blue
per colony by palette swap. The recorded operations are regenerated into the
image, which a reviewer judges against the brief: the raised mound that reads as
a home, the central entrance, and the neutral recolorable palette are what they
weigh.
