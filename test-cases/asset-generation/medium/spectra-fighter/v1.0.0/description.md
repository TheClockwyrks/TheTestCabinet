**Spectra Fighter** is the player's resonator-fighter from _Spectra_, a two-band
formation shooter.

This asset-generation case asks a model to draw it as a 64×64 sprite using only
the drawing tool, one operation at a time: an upward-pointing arrowhead hull with
a glowing cyan core carrying the ring band glyph and twin engine glows. The
recorded operations are regenerated into the image. A reviewer judges that image
against the brief, weighing the ship's upward silhouette, its symmetry, and the
band-by-shape read.
