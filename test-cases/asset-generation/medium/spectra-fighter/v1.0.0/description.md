**Spectra Fighter** is the player's resonator-fighter from *Spectra*, a
two-band formation shooter.

This asset-generation case asks a model to draw it as a 64×64 sprite using only
the drawing tool, one operation at a time: an upward-pointing arrowhead hull
with a glowing **Cyan** core carrying the ring band glyph and twin engine glows.
The recorded operations are regenerated into the image, which a reviewer judges
against the brief — the ship's upward silhouette, its symmetry, and the
band-by-shape read are what they weigh.
