**Thunderhead Broadside** is the capital-ship main-gun report from *Thunderhead*,
a naval fleet-command game. It is the heavy sound a player's battleship fires when
its main battery salvos a target.

This asset-generation case asks a model to author it as a short stereo sound
effect using only the `sfx-sample` audio tool, one operation at a time, by
layering clips from the `combat-core` sample pack: a percussive concussion
transient, a deep sub boom body, a metallic barrel ring, and a rubble/debris tail,
mixed into one four-second report. The tool renders a waveform and spectrogram the
model reads to see its progress. There is no target clip. The recorded operations
are the scored output, not the `.wav` on disk, and a reviewer plays them back
against the brief.
