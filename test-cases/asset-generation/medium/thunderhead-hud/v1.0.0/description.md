**Thunderhead HUD** is the fleet-command interface kit for *Thunderhead*, a naval
fleet-command strategy game.

This asset-generation case asks a model to paint it as a high-resolution **UI
kit** using the `paint` and `ui` binaries, one operation at a time: a bezelled
**command panel**, a stretchable **health-bar frame**, a square **minimap bezel**,
a **faction crest**, and a **primary button** — an industrial, riveted-naval
chassis of gunmetal and brass with cold tactical-cyan readouts and warning amber.
There is no target image; a reviewer judges the emitted per-element PNGs — and
their nine-slice stretch previews — against the brief: the riveted-naval read, the
exact palette, and whether the panel, gauge, bezel, and button stretch cleanly.
