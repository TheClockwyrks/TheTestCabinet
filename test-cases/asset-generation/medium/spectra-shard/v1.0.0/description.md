**Spectra Shard** is the fixed-band crystalline drone from _Spectra_, a two-band
formation shooter. It is the basic enemy and the bulk of every formation.

This asset-generation case asks a model to draw it as a 64×64 sprite using only
the drawing tool, one operation at a time: a faceted magenta crystal carrying the
diamond band glyph. The recorded operations are regenerated into the image. A
reviewer judges that image against the brief, weighing the crystalline silhouette
and the band-by-shape read.
