**Campfire Flames** is a cozy, seamlessly looping campfire: a small fire already
lit and burning steadily in a warm firelight palette.

This asset-generation case asks a model to author it as a volumetric `particle-3d`
effect using only the particle tool, one operation at a time. The model authors an
emitter system instead of individual particles: licking flame tongues that rise
and flicker, yellow-white at the base and cooling to orange then red at the tips;
small embers that pop upward and drift on the heat; and a thin smoke wisp curling
above. Upward buoyancy and a light turbulence shape them, with color, opacity, and
size curves over each particle's life. It is a steady-state effect. The fire is
always burning, so it must loop seamlessly, with no start, no end, and no
burst-and-die.

The recorded operations emit a `system.json`. The review UI simulates it live, and
the simulation is stochastic, so it varies slightly from one play to the next. A
reviewer therefore judges the effect's character across replays and from multiple
orbit angles: its read as a campfire, its heat gradient, its seamless loop, and its
organic flicker.
