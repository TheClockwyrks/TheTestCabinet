**Explosion Animation** is a classic hand-drawn cartoon explosion, the kind of
punchy, stylized blast that punctuates a 2D action game or a cartoon. It is
authored as a sprite sheet of 7 separate 48×48 frames, one drawing operation at
a time.

It plays once. An ignition spark blooms into a white-hot flash, then an
expanding orange fireball with jagged flame tongues, then a smoke-and-debris
peak, then grey smoke thinning to a nearly empty final frame. The whole run is
hot-to-cool: white and yellow hot early, orange and ember through the middle,
grey smoke late. It is drawn in a fixed fire palette on full transparency, so it
composites over anything.

The recorded operations are regenerated into each frame, and the named sequence
plays back as a live one-shot animation in the review UI. A reviewer judges the
frames against the brief, weighing the punchy hot-to-cool progression and the
clean decay to empty.
