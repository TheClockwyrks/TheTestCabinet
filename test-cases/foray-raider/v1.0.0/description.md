**Foray Raider** is the forager caste of *Foray*, a top-down ant-colony raiding
game — the lean, fast ant that crosses into enemy ground, grabs a seed, and
hauls it home. This asset-generation case asks a model to draw it as an animated
**sprite sheet** using only the drawing tool, one operation at a time: a
four-step walk cycle in each of four facings, drawn twice across thirty-two 16×16
frames — empty (0–15) and the same cycles laden with a gold seed (16–31) — with
the body drawn in a neutral grey ramp so the renderer can recolor it red or blue
per colony by palette swap. The recorded operations are regenerated into each
frame, and a reviewer judges them against the brief: the lean mandible-less
silhouette that sets it apart from the soldier, a believable scuttling walk
cycle, the four readable facings, and above all the carry-weight tell — a laden
raider that reads slow and heavy under its gold seed.
