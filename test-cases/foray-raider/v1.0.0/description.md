**Foray Raider** is the forager caste of *Foray*, a top-down ant-colony raiding
game — the lean, fast ant that crosses into enemy ground, grabs a seed, and
hauls it home. This asset-generation case asks a model to draw it as a **sprite
sheet** using only the drawing tool, one operation at a time: eight 16×16 frames
— four empty facings and the same four laden with a gold seed — with the body
drawn in a neutral grey ramp so the renderer can recolor it red or blue per
colony by palette swap. The recorded operations are regenerated into each frame,
which a reviewer judges against the brief: the lean mandible-less silhouette that
sets it apart from the soldier, the four readable facings, and above all the
carry-weight tell — a laden raider that reads slow and heavy under its gold seed.
