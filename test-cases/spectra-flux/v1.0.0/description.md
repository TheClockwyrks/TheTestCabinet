**Spectra Flux** is the oscillating-band drone from *Spectra*, a two-band
formation shooter — an enemy that flickers between cyan and magenta on a
steady rhythm. This asset-generation case asks a model to draw it as a 64×64
sprite using only the drawing tool, one operation at a time, caught
mid-shimmer showing both bands at once and carrying both band glyphs. The
recorded operations are regenerated into the scored image and compared against
the target; the dual-band identity and the band-by-shape read are what a
reviewer weighs.
