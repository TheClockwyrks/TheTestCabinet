---
title: Add or Update a Model
---

Add a new model to the catalog, or refresh the prices, context window, and
release date of the ones already there. A model is two files under
[`models/`](https://github.com/TheClockwyrks/TheTestCabinet/tree/master/models) —
a `<slug>.toml` declaration and a hand-written `<slug>.md` description — plus the
bundled `models.json` dataset the site and consoles ship, regenerated by `tcab
catalog`.

For the full walkthrough and the *why* — the five catalog fields, how `model_ids`
maps a run record back to a model, and how prices are resolved — see [Adding or
Updating a Model](/guides/adding-or-updating-a-model/).

## Prerequisites

- A source checkout with a working Node and Rust toolchain (see
  [Building](/development/building/)).
- The model's **OpenRouter slug** (e.g. `anthropic/claude-sonnet-5`). It must
  already be listed on OpenRouter — `tcab catalog` looks up prices, context
  window, and release date from there.

## Add a new model

```sh
# 1. Scaffold models/<slug>.toml + a placeholder <slug>.md from the OpenRouter slug.
#    Pass an explicit output-slug to match the harness's own id convention when it
#    differs from the OpenRouter tail (Anthropic/OpenAI report a native id).
node scripts/add-model.mjs anthropic/claude-sonnet-5 claude-sonnet-5

# 2. Replace the generated models/claude-sonnet-5.md stub with a real description.
#    See claude-sonnet-4-6.md or gpt-5.4-mini.md for the house style.

# 3. Regenerate the bundled dataset (writes packages/ui/src/app/data/models.json).
cargo run -p test-cabinet-cli -- catalog     # or `tcab catalog` from a release build
```

The script never overwrites an existing `.md`, so re-running it is safe. The
`model_ids` list it generates already covers the native harness id, the
OpenRouter slug, and the OpenCode/Kilo Code `openrouter/` form — leave it as
generated unless a harness reports something else.

## Update existing models

Prices, context windows, and release dates are **not** stored in the `.toml`;
they are refreshed live from OpenRouter. To pull the latest for every model,
re-run the catalog build and commit the result:

```sh
cargo run -p test-cabinet-cli -- catalog
git add models/ packages/ui/src/app/data/models.json
```

To change a model's name, provider, OpenRouter slug, or prose, edit its `.toml` /
`.md` by hand, then re-run `tcab catalog`.

## Verify

```sh
# The new/updated entry should appear with resolved prices and a release date.
node -e 'console.log(require("./packages/ui/src/app/data/models.json").find(m => m.slug === "claude-sonnet-5"))'
```

Commit both the `models/` files **and** the regenerated `models.json` — the site
builds against whatever is committed, with no Rust step of its own.
