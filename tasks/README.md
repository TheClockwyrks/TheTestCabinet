# Tasks

This folder is the repository's issues board. Each issue is one Markdown file,
filed under the epic it is work on and then the area within it, so an issue
against the agent's half of resource governance sits at
`resources/agent/<issue>.md`. A completed issue moves into a `done/` folder
inside the area folder it already sits in, and an issue that needs user input
before it can proceed moves into a `blocked/` folder in the same place.

The policies that govern this folder are in the
[`repo-tasks`](../.claude/skills/repo-tasks/SKILL.md) skill. Read it before
adding or editing an issue.
